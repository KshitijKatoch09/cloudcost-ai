# CloudCost AI - AWS Cost Optimization Platform

Intelligent AWS cost prediction and optimization platform powered by machine learning.

## 🚀 Features

- **Cost Prediction**: ML-powered forecasting of AWS bills
- **Anomaly Detection**: Real-time alerts for unusual spending
- **Smart Recommendations**: Automated cost-saving suggestions
- **Interactive Dashboard**: Beautiful visualizations of cost trends

## 🛠️ Tech Stack

**Frontend:**

- React.js + Vite
- Tailwind CSS
- Recharts

**Backend:**

- AWS Lambda (Serverless)
- API Gateway
- DynamoDB
- Python 3.12

**ML Pipeline:**

- Scikit-learn
- Prophet
- Pandas/NumPy

**DevOps:**

- GitHub Actions
- AWS CloudWatch
- Terraform
